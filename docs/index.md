Fuente única de estilos para las aplicaciones Soffiweb.

Soffi UI usa CSS y JavaScript plano. No requiere Bootstrap, Popper, jQuery,
Tailwind ni Node.

## Documentación

- [Primeros pasos](getting-started.html): instalación, assets y flujo de trabajo.
- [Componentes](components.html): catálogo de clases `sw-*`.
- [Tokens](tokens.html): colores, tipografía, espaciado y compatibilidad.
- [Laravel + Blade](laravel.html): Composer, publicación y patrones Blade.
- [Agentes](agents.html): distribución y activación de la skill.

## Recursos

- [Galería interactiva](gallery/): ejemplos vivos de componentes.
