Inputs & select

Campos de formulario: .sw-field, .sw-input, .sw-select, textarea, toggle, checkbox, radio y select buscable propio (.sw-ss-*).

Campos básicos

Ingresá un correo válido.
No editable una vez creado.
Código 
<div class="sw-field">
    <label class="sw-label">Nombre completo <span class="sw-required">*</span></label>
    <input type="text" class="sw-input" placeholder="Ej. Ana Torres">
</div>

<div class="sw-field">
    <label class="sw-label">Correo</label>
    <input type="email" class="sw-input sw-error" value="correo-invalido">
    <small class="sw-hint-error">Ingresá un correo válido.</small>
</div>

Input con icono

Código 
<div class="sw-input-icon-wrap">
    <i class="fa-solid fa-magnifying-glass sw-input-icon"></i>
    <input type="text" class="sw-input sw-input-has-icon" placeholder="Buscar...">
</div>

Toggle, checkbox, radio

Código 
<button type="button" class="sw-toggle on"></button>
<input type="checkbox" class="sw-checkbox-input" checked>
<button type="button" class="sw-radio on"></button>

Select buscable (.sw-ss-*)

sin dependencia externa
Seleccionar empleado...
Ana Torres
Juan Pérez
Marta Ruiz
Código 
<div class="sw-ss-wrap" id="ss-empleado">
    <div class="sw-ss-trigger" onclick="swToggleSS('ss-empleado')">
        <span>Seleccionar empleado...</span>
        <i class="fa-solid fa-chevron-down"></i>
    </div>
    <div class="sw-ss-dropdown">
        <input class="sw-ss-search" oninput="swFilterSS('ss-empleado', this.value)">
        <div class="sw-ss-opt" onclick="swSelectOpt('ss-empleado', this)">Ana Torres</div>
    </div>
</div>

    <span class="sw-file-input-btn"><i class="fa-solid fa-upload"></i> Elegir archivo</span>

    <input type="file" class="sw-file-input-native" onchange="swFileInputName(this)">
</div>
