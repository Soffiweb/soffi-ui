Collapse / acordeón

data-toggle="collapse" + .collapse/.show — reemplazo propio del collapse de Bootstrap (swToggleCollapse() en soffi-ui.js, listener global, no hace falta onclick). Sin animación: aparece/desaparece directo. Nombres sin prefijo sw- a propósito, son los que ya usaban las vistas.

Simple

Contenido que se muestra u oculta al hacer click en el botón. El panel arranca oculto salvo que tenga .show desde el HTML.

Código 
<button type="button" class="sw-btn sw-btn-ghost sw-btn-sm"
        data-toggle="collapse" data-target="#detalle-1" aria-expanded="false">
    <i class="fa-solid fa-chevron-down"></i> Ver detalle
</button>
<div id="detalle-1" class="collapse">
    ...
</div>

/* opcional: rotar el chevron según aria-expanded */
[data-toggle="collapse"][aria-expanded="true"] .fa-chevron-down {
    transform: rotate(180deg);
}

Código 
<!-- data-parent en el PANEL (no en el trigger) vuelve esto acordeón -->
<div id="acordeon-roles">
    <div class="sw-card">
        <button type="button" class="sw-btn sw-btn-ghost sw-btn-sm"
                data-toggle="collapse" data-target="#acc-1" aria-expanded="true">
            Rol quincenal — septiembre
        </button>
        <div id="acc-1" class="collapse show" data-parent="#acordeon-roles">...</div>
    </div>
    <div class="sw-card">
        <button data-toggle="collapse" data-target="#acc-2" aria-expanded="false">
            Rol quincenal — agosto
        </button>
        <div id="acc-2" class="collapse" data-parent="#acordeon-roles">...</div>
    </div>
</div>
