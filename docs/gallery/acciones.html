Botones

.sw-btn + variante de color. .sw-btn-secondary fue removido del sistema (confundía con primary) — para acciones no primarias usar siempre .sw-btn-ghost.

Variantes

Código 
<button class="sw-btn sw-btn-primary"><i class="fa-solid fa-check"></i> Primary</button>
<button class="sw-btn sw-btn-accent">Accent</button>
<button class="sw-btn sw-btn-success">Success</button>
<button class="sw-btn sw-btn-error">Error</button>
<button class="sw-btn sw-btn-ghost">Ghost</button>
<button class="sw-btn sw-btn-outline">Outline</button>
<button class="sw-btn sw-btn-light">Light</button>
<button class="sw-btn sw-btn-primary" disabled>Disabled</button>

Tamaños

Código 
<button class="sw-btn sw-btn-primary sw-btn-sm">Small</button>
<button class="sw-btn sw-btn-primary">Default</button>
<button class="sw-btn sw-btn-primary sw-btn-lg">Large</button>
<button class="sw-btn sw-btn-primary sw-btn-icon" aria-label="Icono"><i class="fa-solid fa-plus"></i></button>

Botones-icono de fila (.sw-bico)

acciones de tabla: editar/copiar/eliminar/estado
Código 
<button class="sw-bico sw-bico-edit" title="Editar"><i class="fa-solid fa-pen"></i></button>
<button class="sw-bico sw-bico-copy" title="Duplicar"><i class="fa-solid fa-copy"></i></button>
<button class="sw-bico sw-bico-delete" title="Eliminar"><i class="fa-solid fa-trash"></i></button>
<button class="sw-bico sw-bico-success" title="Aprobar"><i class="fa-solid fa-check"></i></button>
<button class="sw-bico sw-bico-info" title="Info"><i class="fa-solid fa-circle-info"></i></button>
<button class="sw-bico sw-bico-warning" title="Alerta"><i class="fa-solid fa-triangle-exclamation"></i></button>
<button class="sw-bico" disabled title="No disponible"><i class="fa-solid fa-lock"></i></button>
