Utilidades

Componentes auxiliares para acciones, estados de carga, ayuda contextual, formularios y procesos largos.

Dropdown

.sw-dropdown + swToggleDropdown(trigger). Un menú genérico para acciones o enlaces. El divider dibuja una línea y separa grupos.

Editar Duplicar
Código
<div class="sw-dropdown">
    <button class="sw-btn sw-btn-primary" aria-haspopup="menu"
            aria-expanded="false" aria-controls="actions-menu"
            onclick="swToggleDropdown(this)">Acciones</button>
    <div class="sw-dropdown-menu" id="actions-menu" role="menu">
        <a href="..." class="sw-dropdown-item" role="menuitem">Editar</a>
    </div>
</div>

Spinner

.sw-spinner indica una operación en curso. Variantes -sm, base y -lg.

Código
<span class="sw-spinner" role="status" aria-label="Cargando"></span>
<button class="sw-btn sw-btn-primary" disabled>
    <span class="sw-spinner sw-spinner-sm sw-spinner-light" aria-hidden="true"></span>
    Guardando
</button>

Tooltip

.sw-tooltip muestra ayuda contextual al pasar el cursor o enfocar el elemento.

Tooltip inferior
Código
<button class="sw-tooltip" data-tooltip="Información adicional"
        title="Información adicional" aria-label="Más información">
    <i class="fa-solid fa-circle-info"></i>
</button>

Switch

.sw-switch es un control de formulario accesible basado en checkbox nativo.

Código
<label class="sw-switch">
    <input type="checkbox" class="sw-switch-input" checked>
    <span class="sw-switch-track" aria-hidden="true">
        <span class="sw-switch-thumb"></span>
    </span>
    <span class="sw-switch-label">Notificaciones activas</span>
</label>

Skeleton

.sw-skeleton mantiene la estructura visible mientras llega el contenido.

Código
<span class="sw-skeleton sw-skeleton-avatar"></span>
<span class="sw-skeleton sw-skeleton-title"></span>
<span class="sw-skeleton sw-skeleton-text"></span>
<span class="sw-skeleton sw-skeleton-media"></span>

Stepper

.sw-stepper representa el avance de un proceso. Usa .is-complete y .is-active.

DatosCompletado
2ConfirmaciónPaso actual
3FinalizarPendiente
Código
<div class="sw-stepper">
    <div class="sw-step is-complete">
        <span class="sw-step-marker">1</span>
        <span class="sw-step-content"><span class="sw-step-title">Datos</span></span>
    </div>
    <div class="sw-step is-active">
        <span class="sw-step-marker">2</span>
        <span class="sw-step-content"><span class="sw-step-title">Confirmación</span></span>
    </div>
</div>

Impresión

Los estilos de impresión ocultan chrome de aplicación y dejan el contenido listo para papel o PDF.

Contenido imprimible

Este texto puede ocultarse al imprimir con .sw-print-hide.

Este texto solo aparece al imprimir con .sw-print-only.

Código
<div class="sw-print-hide">No aparece en papel</div>
<div class="sw-print-only">Solo aparece al imprimir</div>
<section class="sw-print-break-before">Nueva página</section>
