Alerts

.sw-alert — bloque fijo dentro del flujo de la página, para mensajes largos o específicos (listas de errores de validación, avisos). Distinto de Toast: no flota ni se autocierra.

Este mes el cierre de nómina es el día 28.
Departamento creado correctamente.
Hay 3 empleados sin cuenta bancaria registrada.
No se pudo importar el archivo: formato inválido.
Código 
<div class="sw-alert sw-alert-success">
    <i class="fa-solid fa-circle-check"></i>
    <span>Departamento creado correctamente.</span>
</div>
<!-- soffi-ui.js agrega el botón .sw-alert-close y el autocierre a 7s
     solo (swInitAlerts corre en DOMContentLoaded) -->

Toast

.sw-alert.sw-alert-toast — mismo componente que Alert, pero flotante y con autocierre. Para notificaciones cortas de una sola acción puntual ("Producto creado").

Código 
<div class="sw-alert sw-alert-success sw-alert-toast">
    <i class="fa-solid fa-circle-check"></i>
    <span>Guardado correctamente.</span>
</div>
<!-- inyectado por AJAX: document.body.appendChild(el); swInitAlerts(); -->

Banner de impersonación

.sw-impersonation-banner — visible mientras dure la sesión impersonada. A diferencia de .sw-alert, no se autocierra ni entra en swInitAlerts().

Estás viendo el sistema como Juan Pérez (Contabilidad).
Código 
<div class="sw-impersonation-banner">
    <div class="sw-impersonation-banner-text">
        <i class="fa-solid fa-user-secret"></i>
        <span>Estás viendo el sistema como <strong>Juan Pérez</strong>.</span>
    </div>
    <a href="..." class="sw-btn sw-impersonation-banner-exit">Salir</a>
</div>

Estado vacío

.sw-empty-state — línea inline para tablas o listas sin datos.

No hay registros para mostrar.
Código 
<span class="sw-empty-state"><i class="fa-solid fa-inbox"></i> No hay registros para mostrar.</span>
