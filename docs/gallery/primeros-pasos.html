Primeros pasos con Soffi UI

Instala el paquete, publica sus assets y crea tu primera vista Laravel + Blade usando el sistema visual Soffiweb.

Laravel + Blade CSS/JS plano v1.0.0
1 InstalaAñade el paquete con Composer. 2 Carga los assetsPublica CSS y JS en Laravel. 3 Usa el layoutParte del panel base de Blade. 4 Crea componentesUsa las clases y tokens existentes. 5 Personaliza el temaPisa tokens sin tocar el paquete.

1. Instala el paquete

Soffi UI requiere PHP 8.1 o superior y funciona con Laravel 10, 11, 12 y 13. La aplicación consumidora no necesita Node, Bootstrap, jQuery ni Tailwind.

El piso de navegador es Chrome/Edge 109, Firefox 115 ESR y Safari 15.6.

Composer

Instalar Soffi UI 
composer config repositories.soffi-ui vcs https://github.com/Soffiweb/soffi-ui
composer require soffiweb/soffi-ui:^1.0

php artisan vendor:publish --tag=soffi-ui --force

2. Carga los assets

El tag soffi-ui publica CSS y JS en public/vendor/soffi-ui. Inclúyelos en tu layout base.

Layout Blade

Enlaces mínimos 
<link rel="stylesheet" href="{{ asset('vendor/soffi-ui/soffi-ui.css') }}">
<script src="{{ asset('vendor/soffi-ui/soffi-ui.js') }}"></script>

3. Usa el layout de panel

El layout incluye shell, topbar, sidebar, main, footer y soporte de tema claro/oscuro.

Vista base

layouts/dashboard.blade.php 
@extends('soffi-ui::layouts.panel')

@section('title', 'Dashboard')

@section('sidebar')
    <x-sw-sidebar :items="$menu" :brand="config('app.name')" />
@endsection

@section('content')
    <div class="sw-crud-container">
        <h1 class="sw-page-title">Dashboard</h1>
    </div>
@endsection

4. Crea tu primer componente

Usa las clases sw-* existentes. Los colores, radios, espaciados y tipografía vienen de tokens.

Vista previa

Markup 
<button type="button" class="sw-btn sw-btn-primary">
    <i class="fa-solid fa-check"></i> Guardar cambios
</button>

5. Cambia el tema

El botón superior alterna entre claro y oscuro. En una aplicación real puedes usar swToggleTheme() desde tu control de usuario.

Personalización

Declara tus overrides después de soffi-ui.css. No edites los archivos publicados del paquete.

Variables de la aplicación 
:root {
    --sw-primary: #28449a;
    --sw-radius-lg: 0.75rem;
}
