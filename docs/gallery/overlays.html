Modal

.sw-modal-backdrop + .sw-modal. Contrato: swOpenModal(id) reubica el modal como hijo directo de <body> (necesario porque .sw-main crea su propio stacking context). Nunca data-toggle="modal": no hay Bootstrap.

Código 
<button onclick="swOpenModal('miModal')">Abrir</button>

<div class="sw-modal-backdrop" id="miModal">
    <div class="sw-modal" role="dialog" aria-modal="true">
        <div class="sw-modal-title">
            Título
            <button class="sw-modal-close" onclick="swCloseModal('miModal')">&times;</button>
        </div>
        <div class="sw-modal-body">Contenido...</div>
        <div class="sw-modal-actions">
            <button class="sw-btn sw-btn-ghost" onclick="swCloseModal('miModal')">Cancelar</button>
            <button class="sw-btn sw-btn-primary">Guardar</button>
        </div>
    </div>
</div>
