Tokens

Los tokens son la base visual compartida de Soffi UI: definen color, texto, ritmo, profundidad y capas para que una aplicación mantenga coherencia sin repetir valores sueltos.

Cómo usar esta sección

Los nombres públicos usan el prefijo --sw-*. Personaliza esos tokens en el CSS de tu aplicación, después de cargar soffi-ui.css; los componentes resolverán automáticamente los alias internos y conservarán su comportamiento.

Consúmelos

Usa var(--sw-spacing-md) o var(--sw-text-base) en componentes propios.

Personalízalos

Cambia la marca desde :root, sin editar los archivos publicados del paquete.

Respeta el tema

Colores y bordes tienen valores para claro y oscuro; verifica ambos antes de publicar.

Color — modo claro

La paleta separa intención de implementación: usa --sw-primary para acciones principales y los tokens semánticos para estados como éxito, advertencia, error e información.

--sw-primary#28449a
--sw-secondary#4361ee
--sw-accent#fa75ad
--sw-neutral#303237
--sw-success#00ba7b
--sw-warning#fa9700
--sw-error#e11d48
--sw-info#00a4f2
--sw-bg#fdfdff
--sw-surface#edf1fb
--sw-text#151b1e
--sw-sidebar-bg#1e2330

Color — modo oscuro

El tema oscuro reemplaza los valores de color automáticamente mediante [data-theme="dark"]. Define overrides de marca en ambos modos solo cuando necesites una identidad visual específica.

--sw-primary#7da4e0
--sw-secondary#9dbde8
--sw-accent#fb8dc0
--sw-success#00d390

Tipografía

--sw-font-sans: "Inter"

La escala evita que cada pantalla invente tamaños. Elige el token por función: texto de trabajo, label, título de card o cifra destacada.

--sw-text-3xs / 10pxEtiqueta bajo dona (dashboard)
--sw-text-2xs / 11pxNotas al pie, badges
--sw-text-xs / 12pxLabels, hints
--sw-text-sm / 13pxTablas, texto secundario
--sw-text-base / 14pxTexto de trabajo
--sw-text-md / 15pxInputs, botones
--sw-text-lg / 16pxTítulos de card
--sw-text-xl / 20pxTítulo de página
--sw-text-2xl / 22pxCifras de dashboard
--sw-text-3xl / 28pxKPI grandes

Espaciado & radios

Combina espaciado y radios de la misma escala para conservar el ritmo visual. En componentes nuevos, prioriza --sw-spacing-* frente a valores arbitrarios en píxeles.

--sw-spacing-xs / 0.25rem
--sw-spacing-sm / 0.5rem
--sw-spacing-md / 1rem
--sw-spacing-lg / 1.5rem
--sw-spacing-xl / 2rem
--sw-radius-sm / 0.25rem
--sw-radius-md (--r) / 0.65rem
--sw-radius-lg (--rl) / 1.1rem
--sw-radius-pill / 9999px

Sombras

Las sombras comunican elevación: usa la pequeña para separación sutil, la media para cards interactivas y la grande para elementos flotantes.

--sh-sm
--sh-md
--sh-lg

Capas (z-index)

src/tokens/z-index.css

Usa esta escala para que un overlay propio (dropdown, panel flotante o notificación) se ubique frente a los elementos del sistema. No adivines un número ni compitas con modales y toasts.

--sw-z-sticky / 40Navbar superior (position: sticky)
--sw-z-sidebar-backdrop / 50Fondo oscuro detrás del sidebar móvil
--sw-z-sidebar / 60Panel del sidebar móvil
--sw-z-dropdown / 100Select, menú de usuario, menú de fila de tabla
--sw-z-modal-backdrop / 1060Fondo del modal
--sw-z-toast / 1080Notificación flotante
